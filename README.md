# SkillSwap

SkillSwap is a student-to-student skill exchange platform where students can discover skills, connect with peers, and request learning sessions.

## Features

- Browse available skills
- Search for skills
- View student skill listings
- Send learning requests
- View platform statistics
- Flask REST API
- MongoDB database integration
- React frontend

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Lucide React
- CSS

### Backend
- Python
- Flask
- Flask-CORS
- PyMongo
- JWT
- python-dotenv

### Database
- MongoDB Atlas
